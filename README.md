# Практична робота "Об'єктно-орієнтоване програмування"

### Опис завдання

Необхідно спроектувати та реалізувати ієрархію класів для обраної тварини. В основі лежать загальні риси всіх тварин (харчування, подача голосу), які конкретизуються через наслідування: від абстрактної тварини до хижака і, нарешті, до Медоїда (Honey Badger) — безстрашного мешканця саван.

### Деталі реалізації

Використано ланцюжок Animal → Predator → HoneyBadger. 
Перевизначено методи eat(), speak() та hunt() для відображення специфічної поведінки медоїда.
Поля класів захищені (protected та private), а доступ до них реалізовано через конструктори та метод toString().
Додано унікальний метод dig(), що притаманний саме медоїдам.
